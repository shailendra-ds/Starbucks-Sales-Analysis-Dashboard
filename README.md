# ☕ Starbucks Sales Analysis Dashboard

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze Starbucks beverage data and generate meaningful business insights.

The dashboard provides an overview of beverage performance, including calories, sugar, caffeine, beverage categories, beverage preparation types, and protein ranges.

## 🎯 Project Objectives

- Analyze Starbucks beverage categories
- Compare average calories across beverage categories
- Analyze average sugar content
- Analyze average caffeine content
- Analyze beverage category distribution
- Identify beverages with the highest caffeine levels
- Provide interactive filtering for beverage preparation and protein range
- Present insights through an interactive Power BI dashboard

## 📈 Dashboard KPIs

The dashboard includes the following key performance indicators:

- **Total Beverage Count**
- **Average Sugar**
- **Average Calories**
- **Average Caffeine**

## 🔍 Analysis Covered

### Beverage Analysis
- Average Calories by Beverage Category
- Average Caffeine by Category
- Beverage Category Distribution
- Beverage performance comparison

### Caffeine Analysis
- Top 5 Highest Caffeine Beverages
- Average Caffeine by Beverage Category

### Interactive Filters
- **Protein Range**
- **Beverage Preparation**
